# BTCognitive V36.2 — Data and Lineage Admissibility

## Method and interpretation

Read-only inspection of local manifests, files, hashes, and parsed candle series. No network, tests, model execution, replay, or file mutation. Times below are UTC interpretations of the stored timestamps; raw files without an acquisition manifest do not independently establish exchange, pair, or candle-open/close semantics. Hash agreement proves byte identity with the named local manifest, not authenticity of the original exchange feed.

## Raw hourly lineage discrepancy

The V2 acquisition comparison describes a prior 42,233-row primary raw snapshot. Current `data/raw/ohlcv.parquet` contains 42,326 rows. A timestamp join found all 42,237 V2 timestamps in current raw plus 89 additional raw timestamps, but values differ at 40,874 opens, 40,787 highs, 40,799 lows, 40,885 closes, and 40,891 volumes. Therefore the current raw data is not interchangeable with verified Coinbase V2 despite overlap and a Coinbase attribution in some code/docs. No raw-data file or manifest was changed to reconcile this.

## Feasibility by intended analysis

| Intended analysis | Can existing data support it? | Conditions / limitations |
|---|---|---|
| Hourly volatility research | **Conditionally, as a new historical research dataset; not as a verified reproduction of a frozen model.** | Coinbase V2/V3 are the strongest provenance-qualified long-span choice (2022–2026), but contain 13 explicit gaps and do not match frozen HAR-RS-DOW input hash. Current raw is continuous but lineage and material value differences are unresolved. Standard HAR artifact is absent. |
| 15-minute candidate generation | **Potentially.** | Coinbase 15m is continuous but only ~169 days and is not Bitstamp. The Bitstamp-declared 1m intake snapshot can be resampled only after candle-time semantics/source lineage are accepted; the frozen contract requires exact completed 15m decisions and a next-minute fill. No mixing venues to fill gaps. |
| 1-minute barrier outcome resolution | **Structurally yes, provenance-gated.** | The 7.77M-row local 1m file is continuous and its hash matches the research data-intake manifest, but source authenticity and open/close timestamp semantics need an auditable resolution against the V3 contract before trusting outcomes. One-minute OHLC still cannot resolve within-minute ordering when both barriers are touched. |
| Order-book, funding, open interest, liquidation, on-chain features | **No.** | No qualifying synchronized source was established. They must be `DATA_UNAVAILABLE`; do not synthesize them from OHLCV. |

**Bottom line:** historical computation is possible on some local files, but dataset suitability is purpose-specific. The existing 1m entry/exit research path is the only local data candidate with a matching intake SHA, yet its source and candle timestamp semantics remain the gating lineage evidence. The frozen HAR-RS-DOW training data mismatch and missing Standard HAR artifact independently prevent existing HAR accuracy claims.
