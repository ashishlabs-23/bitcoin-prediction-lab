# BTCognitive V37.4 — Exchange Source and Licensing Review

**Review date:** 2026-11-04  
**Scope:** Public BTC/USD spot market data only. This report is an engineering source review, not legal advice or a grant of data rights.

## Recommendation

Keep **Bitstamp BTC/USD** as the provisional canonical feed, consistent with the V37.4 owner-specified source strategy and the successful public WebSocket subscription smoke test. This is a technical selection only. Bitstamp's official WebSocket documentation and substantive data-use terms could not be retrieved during this review; those rights and operational guarantees remain unverified. Keep raw-event persistence, redistribution, and model-research use gated on an owner/legal review of the applicable terms.

Do not silently substitute another venue. Keep each venue's prices, quantities, event IDs, and candle series separate.

## Repositories and historical candidates

- [`bmoscon/cryptofeed`](https://github.com/bmoscon/cryptofeed) supports multiple exchange feeds, but its code is **AGPL-3.0-or-later**. Reviewed revision: `3128a3bed0c06812751b528d35f89debb22a5202`. It was not added as a dependency. Its adapter is implementation corroboration, not an exchange guarantee or data license.
- [`ff137/bitstamp-btcusd-minute-data`](https://github.com/ff137/bitstamp-btcusd-minute-data) describes BTC/USD one-minute OHLCV, not trades or order-book data. Its stated dataset terms distinguish Kaggle-derived historical rows (CC BY-SA 4.0) from API-collected updates (CC BY 4.0). The README reports flat, zero-volume gap filling; those rows cannot be treated as observed trades or zero-volume market intervals. The repository MIT license covers code, not necessarily underlying exchange data.
- Hugging Face [`mrorigo/btc_bitstamp_1min`](https://huggingface.co/datasets/mrorigo/btc_bitstamp_1min) reports 4.86M rows and fields including `Timestamp`, OHLC, `Volume_(BTC)`, `Volume_(Currency)`, and `Weighted_Price`; the card has null OHLCV examples and timestamp values consistent with Unix seconds. The card's `mit` label does not prove upstream data rights. No dataset files were downloaded or audited row-by-row.
- Hugging Face [`WinkingFace/CryptoLM-Bitcoin-BTC-USDT`](https://huggingface.co/datasets/WinkingFace/CryptoLM-Bitcoin-BTC-USDT) is BTC/USDT, includes precomputed indicators, and has no verified exchange provenance in the reviewed card. It is not BTC/USD and is excluded as a substitute.

Existing local historical files remain as characterized in [V37.3 data qualification](./V37_3_DATA_QUALIFICATION.md) and [V37.3 research recovery](./V37_3_RESEARCH_RECOVERY_REPORT.md): source corroboration is not source authentication. No historical dataset was modified, merged, backfilled, or opened for model selection.

## Technical follow-up gates

1. Recheck Bitstamp's official channel, heartbeat, timestamp-unit, trade-ID, reconnect, REST recovery, and terms documentation from an accessible official source.
2. Obtain owner/legal confirmation for intended retention and use before durable event recording, model research, commercial use, or redistribution.
3. Keep Coinbase model-data use disabled absent written permission; keep Gemini and Kraken collection gated pending rights decisions.
4. Do not adopt AGPL Cryptofeed without explicit licensing approval.
